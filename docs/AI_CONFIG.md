# 🤖 AI 助手配置指南

## 📋 概述

本系统集成了 **Moonshot AI (Kimi)** 智能客服功能，可以回答停车相关问题、提供车库状态查询等服务。

## 🔑 获取 API Key

### 1. 注册 Moonshot AI 账号

访问 [Moonshot AI 开放平台](https://platform.moonshot.cn/)：
- 点击"注册/登录"
- 使用手机号或邮箱完成注册
- 完成实名认证（根据平台要求）

### 2. 创建 API Key

登录后：
1. 进入"控制台" → "API 管理"
2. 点击"创建新的 API Key"
3. 复制生成的 API Key（格式：`sk-xxxxxxxxxxxxxxxx`）
4. ⚠️ **重要**：API Key 只显示一次，请妥善保存

### 3. 充值账户（可选）

- Moonshot AI 提供免费额度供测试
- 如需长期使用，建议充值：进入"账户" → "余额管理"

## ⚙️ 系统配置

### 在管理后台配置

1. 登录系统后台（默认账号：admin / admin123）
2. 导航至：**后台管理** → **AI 助手配置**
3. 填写配置信息：

   | 配置项 | 说明 | 示例 |
   |--------|------|------|
   | **API Key** | 从 Moonshot AI 获取的密钥 | `sk-xxxxxxxxxxxxxxxx` |
   | **AI 模型** | 选择使用的模型版本 | `moonshot-v1-8k`（推荐） |
   | **角色提示** | 自定义 AI 的角色和行为 | "你是一个专业的停车助手..." |

4. 点击"保存配置"

### 模型选择建议

| 模型 | 上下文长度 | 适用场景 | 费用 |
|------|-----------|---------|------|
| **moonshot-v1-8k** | 8,000 tokens | 日常问答、快速响应 | 较低 ✅ |
| **moonshot-v1-32k** | 32,000 tokens | 复杂对话、长文本分析 | 较高 |
| **moonshot-v1-128k** | 128,000 tokens | 超长文本处理 | 最高 |

**推荐使用 `moonshot-v1-8k`**，适合停车系统的问答场景。

## 🧪 测试配置

配置完成后：

1. 打开系统首页
2. 点击右下角的蓝色聊天按钮
3. 输入测试问题，例如：
   - "当前车库有多少车位？"
   - "停车费用怎么计算？"
   - "如何入场出场？"

4. 如果收到回复，说明配置成功 ✅

## ❌ 常见错误及解决方案

### 1. "请先在 AI 助手配置中配置 Moonshot AI API Key"

**原因**：未配置或配置为空

**解决**：
- 进入"AI 助手配置"页面
- 检查 API Key 是否正确填写
- 确保没有多余的空格

### 2. "API Key 无效或已过期"

**原因**：API Key 错误或已被删除

**解决**：
- 登录 Moonshot AI 平台检查 API Key 状态
- 重新创建新的 API Key
- 在系统中更新配置

### 3. "网络连接超时"

**原因**：网络问题或防火墙拦截

**解决**：
- 检查服务器网络连接
- 确认可以访问 `https://api.moonshot.cn`
- 检查防火墙/代理设置

### 4. "API 调用配额已用尽"

**原因**：免费额度用完或账户余额不足

**解决**：
- 登录 Moonshot AI 平台查看余额
- 充值账户
- 或等待下个月免费额度刷新

## 🔒 安全建议

1. **不要泄露 API Key**
   - 不要在公开的代码仓库中提交 API Key
   - 不要在前端代码中硬编码 API Key
   - 定期更换 API Key

2. **设置合理的调用频率限制**
   - 在 Moonshot AI 平台设置每日/每月调用上限
   - 避免恶意用户滥用

3. **监控使用情况**
   - 定期检查 Moonshot AI 控制台的使用统计
   - 发现异常立即更换 API Key
